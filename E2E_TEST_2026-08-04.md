## Findings

### F1 — QC persistence collided on repeated injection names (FIXED)

`qc_results` is unique on `(batch_id, analyte, qc_type, qc_level)` and the IS
rows used `qc_level = injection_name`. **This export contains three CCV
injections all named `FDA-CCV-251020`**, distinguished only by acquisition time,
so three IS rows per compound shared a key: `UNIQUE constraint failed`.

Two defects, not one:

1. The key assumed injection names are unique within a run. Real instrument data
   does not honour that. `concat_id` — documented as
   `"injection_name|yyyymmddHHMMSS (unique key)"` — already existed for exactly
   this and was not being used.
2. **The failed insert rolled back and left the PREVIOUS run's 496 rows in
   place**, reported only as one ERROR line. Data Review would have gated on
   stale QC and said nothing. The persist now clears the batch's rows on
   failure, so the gate reports "no QC record" and blocks — the honest state.

Masked until today because the relabelled fixture gave the CCVs distinct names.
A fixture that tidies the data hides the defects the data would have found.

### F2 — LFSM/LFSMD blocked with no resolution path

`batch.spikes` is empty when no extraction log is passed, so LFSM and LFSMD
produce no results and the gate correctly reports *"required QC not evaluated:
LFSM, LFSMD"*. But `pending_spike_levels()` offers **0** entries, so the reviewer
is given no way to supply the missing spike level — which is precisely what the
2026-08-03 decision ("allow the user to input the spike level if it is missing")
was meant to provide. The prompt keys off recorded pedigree entries that do not
exist when the pedigree itself is absent. **Open.**

### F3 — the relabelled fixture no longer matches the SENAITE samples

First run pushed only 32 of 288: the samples carry the ORIGINAL injection names
as ClientSampleID (`KCP Silage "Egg-1" Sample`) while the relabelled fixture uses
`FDA_32PFAS-FEED-0002`. Fixture/state drift, not a code defect — re-running with
the original export gave 288/288. Worth deciding which of the two fixtures is
canonical, because they now test different things.
